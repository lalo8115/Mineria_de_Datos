## Descripción de la Práctica

En esta práctica se construyó un modelo de regresión lineal a partir del conjunto de datos de Netflix, con el objetivo de analizar la relación entre variables cuantitativas y evaluar su grado de correlación. 

Se utilizaron herramientas de modelado estadístico para:

- Calcular la correlación entre variables.
- Ajustar un modelo de regresión lineal.
- Visualizar el modelo mediante gráficos de dispersión y rectas de ajuste.
- Obtener y analizar el valor R² para evaluar el desempeño del modelo.

## Observaciones y Comentarios

El modelo lineal ajustado permitió observar una tendencia general entre el año de lanzamiento y la duración del contenido, aunque se identificó que la correlación no es fuerte. Aun así, el ejercicio fue útil para aplicar conceptos de correlación, regresión y métricas de desempeño.
