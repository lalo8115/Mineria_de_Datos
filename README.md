## Descripción de la Práctica

En esta práctica se implementaron pruebas estadísticas para determinar si existen diferencias significativas entre grupos de datos etiquetados. Se utilizaron pruebas paramétricas y no paramétricas como:

- **ANOVA (Análisis de Varianza)**  
- **Prueba de Kruskal-Wallis**  
- **Prueba t de Student** (cuando fue aplicable)

El objetivo fue demostrar que los datos etiquetados presentan diferencias estadísticamente significativas en alguna de sus características, utilizando herramientas estadísticas sobre variables cuantitativas y categóricas.

## Observaciones y Comentarios

Se observó que variables como la duración de películas y el año de lanzamiento muestran diferencias estadísticas significativas entre distintas clasificaciones y tipos de contenido, lo cual puede ser útil para segmentación o análisis más profundo.
