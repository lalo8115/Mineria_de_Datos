## Descripción de la Práctica

En esta primera práctica se aborda el proceso de limpieza de datos, fundamental para garantizar la calidad y confiabilidad de los análisis posteriores en minería de datos. Se trabajó con un conjunto de datos real con las siguientes características:

- Dataset con más de 5000 filas y al menos 4 variables.  
- Variables numéricas, alfanuméricas y de fecha.  
- Tratamiento de valores nulos, formato de fechas, y estandarización de columnas.  

El objetivo principal fue preparar el dataset para futuras etapas de análisis y modelado, eliminando inconsistencias y mejorando la calidad de la información.
