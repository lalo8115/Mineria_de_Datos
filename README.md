## Descripción de la Práctica

En esta octava práctica se trabajó el tema de **forecasting o pronóstico de series temporales** utilizando un modelo de **regresión lineal simple**. El objetivo fue predecir valores futuros a partir de un conjunto de datos ordenado cronológicamente. Se aplicaron técnicas de visualización, preparación de datos, partición en entrenamiento y prueba, y evaluación del modelo.

El enfoque consistió en:

- Utilizar una serie de tiempo real (por ejemplo, ingresos mensuales, temperatura diaria, etc.).
- Aplicar regresión lineal sobre la variable dependiente con respecto al tiempo.
- Visualizar el modelo y evaluar su capacidad de predicción.
