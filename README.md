## Descripción de la Práctica

En esta tercera práctica se exploraron técnicas de visualización de datos mediante gráficos estadísticos. El objetivo fue representar gráficamente la información contenida en un conjunto de datos, facilitando su interpretación y análisis.

Las visualizaciones generadas incluyeron:

- Diagramas de pastel (pie charts)
- Histogramas
- Diagramas de caja (boxplots)
- Gráficos de líneas y de barras
- Diagramas de dispersión (scatter plots)

Se utilizó programación con bucles (`for`) para automatizar la creación de múltiples visualizaciones, generando al menos cinco tipos distintos de gráficas.
